## Project spotlight

[![MNG Construction — project galleries, estimates, reviews and a mobile admin dashboard](assets/mng-project.svg)](https://mng-construction.vercel.app/)

**MNG Construction** is a public website prototype for a Calgary company working in landscaping, siding, roofing and snow removal.

- A project gallery with multiple photos and before/after views.
- A step-by-step estimate request connected to EmailJS.
- A Supabase-backed admin dashboard for projects, photos and reviews.
- Customer feedback that is reviewed before publication, with public replies.

<br>

| Visitor experience | Owner experience |
| :--- | :--- |
| Browse published projects and photos | Add and edit projects from the admin dashboard |
| Send an estimate request | Receive the request by email |
| Leave a review without creating an account | Approve, hide and reply to feedback |
| Read approved reviews and replies | Publish content without editing website code |

Supabase controls access to content. Public visitors see published projects and approved reviews, while the admin account manages updates.
